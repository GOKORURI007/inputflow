# InputFlow 需求说明书

## 1. 项目定位

一个轻量级、高性能的 Python 跨平台键鼠共享工具。通过网络将一套物理键鼠的操作同步至多台电脑，支持在 Windows、macOS 和 Linux（含
Hyprland/Wayland）之间无缝切换。

## 2. 核心架构设计

为了平衡开发难度与性能，程序采用 ** 后端自适应架构 **：

* **Server (服务端)**：负责捕获物理输入。
* **Client (客户端)**：负责接收并模拟输入。
* ** 通信层 **：基于 UDP，传输归一化坐标。

---

## 3. 技术栈选型

根据平台环境自动切换底层驱动：

| 操作系统                 | 捕获方案 (Server) | 模拟方案 (Client) | 理由                        |
|----------------------|---------------|---------------|---------------------------|
| **Windows**          | `pynput`      | `pynput`      | 标准 Win32 API 适配良好。        |
| **macOS**            | `pynput`      | `pynput`      | 基于 Quartz 框架，简单稳定。        |
| **Linux (Hyprland)** | **`evdev`**   | **`uinput`**  | 绕过 Wayland 权限限制，实现内核级流畅度。 |

---

## 4. 功能需求

### 4.1 桌面拓扑 (Topology)

* ** 屏幕对齐 **：通过 TOML 定义逻辑位置（Left/Right/Up/Down）。
* ** 边缘穿透 **：当鼠标触碰 Server 屏幕设定边缘时，锁定本地光标，激活远程模式。
* ** 坐标转换 **：将绝对像素转换为 至 的归一化浮点数，解决异构分辨率缩放问题。

### 4.2 键鼠同步逻辑

* ** 鼠标 **：支持实时移动、点击、滚轮。
* ** 键盘 **：支持按键按下 / 弹起（Key Down/Up）。
* ** 低延迟优化 **：
* 对高频鼠标移动事件进行微秒级节流控制。

### 4.3 快捷键与锁定

* ** 全局锁定 **：按下快捷键（如 `Ctrl+T`）禁止 / 启用边缘自动切换，防止游戏时意外滑出。
* ** 循环切换 **：通过快捷键直接将控制权在所有客户端之间循环切换。

## 5. 配置文件规范 (`config.toml`)

程序启动时默认读取同目录下的配置文件，无需人工干预。

```toml
[network]
role = "server"        # 角色：server 或 client
bind_ip = "0.0.0.0"
port = 24800
tcp_nodelay = true

[[topology]]
# 格式：方向 = 目标 IP
self = "192.168.123.154"
right = "192.168.123.15"
left = ""

[[topology]]
self = "192.168.123.15"
right = ""
left = "192.168.123.154"

[shortcuts]
switch_lock = "ctrl+t"
switch_loop_between_screens = "ctrl+`"

```

---

## 6. 非功能性需求（从简）

* ** 异常处理 **：一切从简。
* ** 安全 **：初版仅支持局域网明文传输，不考虑 SSL 加密（若需要可后续增加）。
* **UI**：全命令行交互，仅输出简易日志，可使用 loguru。

---

## 7. 运行流程图

1. ** 启动 **：读取 TOML。Linux 环境检查 `/dev/input` 和 `/dev/uinput` 权限。
2. ** 监听循环 **：捕获端获取原始输入。
3. ** 边界判定 **：如果鼠标位置 > 屏幕宽度 且 `topology.right` 存在，触发切换。
4. ** 数据分发 **：将事件封装为二进制包通过 Socket 发送。
5. ** 执行模拟 **：客户端解析包，直接调用底层 API 执行动作。
